# Публичный debug-ключ

`debug.keystore` — намеренно публичный тестовый PKCS12-ключ для личных сборок.
Он не является production-секретом и не должен использоваться для публикации
приложения, защиты данных или подтверждения личности разработчика.

- Тип хранилища: `PKCS12`.
- Alias: `androiddebugkey`.
- Пароли хранилища и ключа: `android`.
- Сертификат: `CN=Android Debug, O=Android, C=US`.

Один и тот же ключ используется для debug и release APK во всех запусках CI,
поэтому личные сборки можно обновлять без удаления приложения. Release остаётся
неотладочным (`isDebuggable = false`), несмотря на тестовую подпись.

Для публикации нужен отдельный приватный release-ключ, хранящийся вне Git.
Настоящие ключи, пароли и токены в этот каталог добавлять нельзя.
